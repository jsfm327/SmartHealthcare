# 基于SpringBoot的智能医疗系统 - 项目设计方案

## 一、项目概述

**项目名称：** 基于SpringBoot的智能医疗系统的设计与实现

**技术栈：**
- 后端：Spring Boot 3.2+ / MyBatis-Plus / JWT / Spring AI
- AI模型：通义千问（DashScope）
- 数据库：MySQL 8.0 + Redis
- 前端：Vue.js（前端独立设计，本文档仅涉及后端）
- 构建工具：Maven

**3. 实现类示例（ConsultServiceImpl）：**

```java
@Service
public class ConsultServiceImpl implements ConsultService {

    @Autowired
    private ChatClient chatClient;

    @Autowired
    private ConsultRecordMapper consultRecordMapper;

    private static final String SYSTEM_PROMPT = """
        你是一个智能医疗问诊助手。用户会描述自己的症状，请你：
        1. 分析可能的病因
        2. 给出初步的健康建议
        3. 建议用户前往哪个科室就诊
        请以JSON格式返回，包含字段：analysis(分析)、advice(建议)、department(建议科室)
        注意：你不能开具处方或做出诊断，仅提供参考建议，请提醒用户及时就医。
        """;

    @Override
    public ConsultVO askQuestion(Long userId, String symptoms) {
        // 调用大模型获取AI回复
        String response = chatClient.prompt()
            .system(SYSTEM_PROMPT)
            .user(symptoms)
            .call()
            .content();

        // 解析AI返回的JSON，提取建议科室等信息
        JSONObject result = JSON.parseObject(response);
        String analysis = result.getString("analysis");
        String advice = result.getString("advice");
        String department = result.getString("department");

        // 保存问诊记录
        ConsultRecord record = new ConsultRecord();
        record.setUserId(userId);
        record.setTitle(symptoms.substring(0, Math.min(50, symptoms.length())));
        record.setSymptoms(symptoms);
        record.setAiResponse(response);
        record.setDepartmentSuggest(department);
        record.setStatus(1);
        consultRecordMapper.insert(record);

        // 组装返回VO
        ConsultVO vo = new ConsultVO();
        vo.setId(record.getId());
        vo.setSymptoms(symptoms);
        vo.setAnalysis(analysis);
        vo.setAdvice(advice);
        vo.setDepartmentSuggest(department);
        return vo;
    }
}
```
